## 插件模板

::: code-tabs#install

@tab GitHub（国外推荐）

```sh
git clone -b lib --depth 1 https://github.com/TRSSo/Philia-App-Template plugin/template
pnpm i -P
```

@tab Gitee（国内推荐）

```sh
git clone -b lib --depth 1 https://gitee.com/TRSSo/Philia-App-Template plugin/template
pnpm i -P
```

@tab GitLab

```sh
git clone -b lib --depth 1 https://gitlab.com/TRSSo/Philia-App-Template plugin/template
pnpm i -P
```

@tab GitCode

```sh
git clone -b lib --depth 1 https://gitcode.com/TRSSo/Philia-App-Template plugin/template
pnpm i -P
```

@tab 开发

```sh
git clone -b dev --single-branch https://github.com/TRSSo/Philia-App-Template plugin/template
cd plugin/template
pnpm i
pnpm build
```

:::
